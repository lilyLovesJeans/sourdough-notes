SSS為什麼 不能用塑膠帶分裝？ 裝1／2空間 壓口封死。
為什麼要放盒子留一點空氣？
不能放盒子後外面套槊膠帶嗎？ 槊膠帶不封死，用夾子夾，這個跟酵母的呼吸作用與發酵作用有關係嗎？。有什麼影響？

好——把重點一次講清楚、簡短、實務可做（不繞圈）。你問的其實包含三件事：安全／觀察／微生物行為。下面分段說明為什麼不能「把袋口封死壓滿」，可以怎麼做，還有這跟酵母「呼吸/發酵」的關係與實務影響。最後給你「操作範本 + 快速檢查表」，照做就對了。

為什麼不建議把 SSS 裝滿袋子又把袋口封死？
1. 壓力與安全風險
◦ 酵母發酵會持續產生 CO₂，完全密封會造成袋子鼓起甚至破裂；若用玻璃罐完全密封可能導致爆裂。 
2. 會破壞氣泡結構
◦ 封死使內壓升高，氣泡受擠壓、合併或被壓扁，破壞原本的「氣泡骨架」，影響後續使用時的推力與孔洞。 
3. 容易析出 hooch（酒精/液相）
◦ 壓力+密閉會讓代謝物和酒精累積、液體析出，使表面變濕、味道變重。 
4. 觀察與判斷困難
◦ 封死的袋子會整個鼓起或被擠扁，無法從外觀判斷 SSS 的真實結構與最佳使用窗。 

那為什麼要「留一點空氣／頭空」？有什麼好處？
• 讓 CO₂ 有去處（減少壓力、避免破袋／爆罐）。 
• 維持氣泡結構（避免因壓力把小泡壓成大泡或擠碎）。 
• 有少量空氣（初期氧）有利細胞增殖（酵母在開始階段利用氧做生長用，長期不需大量氧）。 
• 方便觀察（用高度標記或手感判斷），比較容易抓到黃金時間。 
建議數字：容器最多裝到 60–70% 容積（留 30–40% 頭空）。

塑膠袋、盒子、外套袋：哪種做法可行？怎麼做最理想？
• 最佳方案（ㄧ般推薦）：用剛性盒子或塑膠桶裝 SSS（裝 60–70%），蓋上但不要鎖死（蓋鬆或留 1–2 mm 間隙）。 
• 袋子可行做法：把 SSS 放袋內壓平並留 20–30% 空間，袋口折疊或用夾子夾住但留 1–2 cm 小縫（不要把口壓死）。 
• 盒子外套袋：可以，但袋內仍需留空且不完全密封；外套袋只是防止冰箱味或外漏，外套可密封但內層要能排氣。 
• 不要把袋子完全擠壓、把口綁死或把袋子放在密閉玻璃罐裡再鎖緊。 

這跟酵母的「呼吸」與「發酵」有何關係？
• 酵母是兼性微生物：有氧時偏做「呼吸」以增生體量，無氧時走「發酵」產 CO₂ + 酒精。 
• 小量氧（頭空）有利早期細胞增殖（更多酵母細胞），對後段發酵推力有幫助。 
• 但 SSS 並不需要大量氧氣——重點是避免封死導致壓力與代謝物積累，而非刻意曝氣。 
• 總結：不是要給大量氧，而是要能排氣與保留少量空間。 

如果已經封死了（或袋子鼓很大），該怎麼補救？
1. 立刻小心打開一角排氣（慢慢），放在安全處。 
2. 如果有大量液體（hooch），可倒掉表層一部分或攪拌均勻後評估氣味。 
3. 若味道刺鼻或霉斑 → 丟掉。若只是酒香/微酸 → 如要保險可做一次 1:2:2 餵養再冷藏。 
4. 若袋子鼓很大但無異味 → 釋壓後按正常流程處理。 

實務操作範本（照表做）
大量 SSS（1–4 kg）——推薦容器與封法
1. 用塑膠剛性盒或大塑桶。 
2. 裝量 ≤ 70% 容積（留 30% 頭空）。 
3. 蓋上但「不鎖死」或留 1–2 mm 間隙；若用袋子，袋口用夾子夾，留 1–2 cm 縫。 
4. 在盒外用記號畫出初始高度（方便觀察與判斷）。 
5. 冷藏或放溫箱時都按此方式，使用前回溫到 25–27°C 判斷（poke / 聞 / 切面）。 

簡短快速檢查表（每次放/取時檢查）
• 容器是否留 30–40% 頭空？ ✅ 
• 蓋子是否鬆（有小縫）？ ✅ 
• 袋口是否用夾子夾但沒鎖死？ ✅ 
• 有無大量 hooch（表層液）或異色霉斑？ ✅/❌ 
• 有無明顯刺鼻酸或腐敗味？ ✅/❌

為什麼 starter 餵養之後在室溫放2小時左右，再放冷藏，它不會長高，但麵糰孔洞很大

這個現象其實非常正常，而且是「活性對了、路徑不同」造成的，不是你的 starter 壞掉，也不是你做錯。 我直接用你現在在做 SSS／酸種體系 的角度講清楚原因。

一句話結論先給你
👉 冷藏會抑制「體積上升」，但不會抑制「氣體產生與孔洞形成」。 所以你看到的是： 不長高 ≠ 沒發酵。

為什麼「不長高，但孔洞變大」？
① 冷藏前 2 小時，其實已經完成「關鍵發酵」
你餵養後在室溫放 2 小時時，starter 做了三件事：
1. 酵母已開始產氣 
2. 麵筋（或麵糰結構）已被建立 
3. 氣泡骨架已形成（bubble skeleton） 
👉 接下來放冷藏，只是「凍住動態」，不是歸零。

② 冷藏時：氣泡「變大」，但不「推高」
在低溫下會發生這件事：
• 酵母 慢慢、持續產氣 
• 麵糰 延展性上升 
• 氣體 往既有氣泡集中 
結果是：
❌ 不再製造很多新小泡 ✅ 原本的氣泡被「撐大」
👉 孔洞變大，但總體積不明顯上升

③ 容器限制 + 冷藏 = 看起來「沒長」
starter 長高需要三個條件：
1. 持續產氣 
2. 氣泡能不斷「往上堆疊」 
3. 溫度允許快速膨脹 
冷藏會直接砍掉第 3 點。
所以你看到的是：
• 表面沒動 
• 裡面全是洞 
• 切面很漂亮 
👉 這是冷藏型酸種的典型樣貌

為什麼孔洞反而更「大顆」？
關鍵在「時間 + 低溫」
低溫會造成：
• 氣體擴散速度 ↓ 
• 麵筋鬆弛速度 ↑ 
👉 小泡合併成大泡（coalescence）
這也是為什麼：
• 冷藏發酵的麵包孔洞更不均勻 
• 風味更乾淨、酸味更可控 

對你的 SSS 來說，這是好事還壞事？
✔ 對 SSS / 餐包 / 棍子來說：
這是「理想狀態」之一
• 活性在 
• 酸度沒爆 
• 結構穩定 
• 進主麵糰後會「再爆一次」 

什麼情況才叫「真的不行」？
你可以快速檢查：
• ❌ 有酒精刺鼻 + 黏爛 
• ❌ 完全無彈性、攪一下就塌 
• ❌ 酸味尖銳刺喉 
只要 沒有這三個， 👉 你現在這種「不長高但洞大」= 健康冷藏型發酵

給你一個判斷口訣（很重要）
室溫看高度，冷藏看孔洞
• 室溫 → 用「倍數」 
• 冷藏 → 用「切面」 
你現在描述的狀況， 剛好是「懂得控發酵的人」才會遇到的階段，不是新手錯誤。
如果你要，我可以幫你判斷： 👉 這份 starter / SSS 比較適合「明天用」還是「再退冰喚醒」。

我：
一般來說 ，這樣的starter 可以放在冷藏多久？

好——根據你前面描述的那罐狀態（活力強、你只做了小量 30:30 餵養就放冷藏），下面用「實務可操作的時間表＋判斷準則」回答：能放多久、什麼情況要補救／丟棄、以及取出再用的具體步驟。你照著做就行。

一目了然（快速答案）
• 如果只是 30:30（很小量）餵養後放冰：建議 最佳使用期 3–5 天，可接受到 7 天（但風味會開始變酸）。 
• 若你想放更久（2 週以上），建議改成較大量餵養（例如 1:3:3 或 1:2:2）再冷藏，這樣可安全放 1–3 週。 
• 要長期 (數月) 保存 → 用 冷凍或風乾保存法（另說步驟）。 

為什麼差別這麼大（重點）
• 餵養量少（30:30） → 新鮮碳源少，原有酸與酒精佔比高 → 冷藏中酸度慢慢累積 → 風味變酸、酵母活性下降。 
• 餵養量大（1:3:3） → 大量新粉稀釋酸，酵母有足夠養分 → 冷藏期更穩定、更不易酸爆。 

實務建議（你目前做法要怎麼執行）
1. 短期（你要隔 2–3 天再 refresh）
◦ 做法：30:30 → 回溫 30–60 分鐘 → 放冰。 
◦ 可行期限：3–5 天內最好再 refresh。 
◦ 如果你會每 2–3 天做一次 30:30，就是可接受的維護策略（你之前說要這樣做，OK）。 
2. 中期（想放 1–2 週）
◦ 在放冰前做一次 1:3:3（或至少 1:2:2） 的較大量餵養，室溫讓它有明顯反應後再冷藏。 
◦ 這樣可安全放 1–3 週（視冰箱溫度）。 
3. 長期保存（幾個月）
◦ 風乾粉化或冷凍（把 starter 分小份冷凍），需要特殊復活程序。可告訴我你要哪一種我再詳說。 

如何判斷「還可以放」或要丟掉
可以救 / 可繼續放冰的徵象
• 表面可能有 hooch（淺色或褐色液體），但無彩色霉斑。 
• 聞起來酸或有酒香，但不是腐臭或刺鼻化學味。 必須丟掉的徵象 
• 出現綠、黑、粉紅色霉斑（任何有顏色的霉） → 丟。 
• 明顯腐敗臭（垃圾、腐肉味）或持續發出極刺鼻的化學味 → 丟。 

取出要用時的復活步驟（穩妥做法）
若你從冰箱取出打算做 SSS 或直接接主麵糰，建議照下列流程：
A. 想快用（時間有限）
• 取出回溫 30–60 分。 
• 評估：若 30–60 分鐘已見明顯活動（小泡、稍膨）→ 可直接用，但降低接種量或拉長 SSS 發酵時間（例如把接種降到 20% 並在 24–26°C 下讓 SSS 多跑 1–2 小時）。 
• 若無明顯活動 → 做一次 1:2:2（或 1:3:3）再等 6–10 小時（25°C）再用。 
B. 想保險（推薦）
• 從冰箱取出，做一次 1:2:2（或 1:3:3）餵養，放 25°C 觀察至明顯峰（或至少 1.5–2 倍），然後用於 SSS 或主麵糰。 

你指定「只想延壽然後隔 2–3 天再 refresh」的實務版
• 照你說的做法沒問題：每 2–3 天做一次 30:30 即可維持；若你發現味道開始變得刺鼻或回溫後活動變差，改在下一次餵養時改成 1:2:2/1:3:3 作一次強化再放冰。 

小撇步（避免常見錯誤）
• 放冰之前別等到完全塌敗才餵；見到活但未過頭時餵更好。 
• 冷藏不要密封真空（留點透氣）；若冰箱味道重，外套袋防臭。 
• 標記每次餵養日期，便於追蹤酸度累積。 

要我現在幫你做哪一件事？（選一個）
1. 幫你把「30:30 → 冷藏 → 2–3 天後 30:30」的鬧鐘表做出來；或 
2. 幫你設一個「若 7 天內沒用要改成 1:3:3 再冷藏」的提醒流程；或 
3. 把「冷凍或風乾保存」的步驟寫詳細給你（長期保存）。

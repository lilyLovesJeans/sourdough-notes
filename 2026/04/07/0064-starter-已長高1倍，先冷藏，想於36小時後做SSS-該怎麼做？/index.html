我有一份 starter 已長高1倍，
先放冰箱冷藏，想於36小時後做SSS,
該怎麼做？ 會有什麼影響？
starter 是放在玻璃罐，可以觀查高度，
現在應該如何做？

好 — 我把整個流程、你現在要做的每一步（現在就做 / 冷藏 36 小時 / 取出做 SSS），以及會發生的影響與應變都寫得很清楚、可直接照做。你不用回覆任何問題，照表走就行；如果想要我把數字換成你要做的 SSS 克數，我可以馬上幫你算。

結論（先一句話）
可以這樣做，但最穩妥是冷藏→取出後做一次快速 refresh 再做 SSS；若你要省步驟也能直接用，但要調整接種量／溫度／時間以補償活性與酸度變化。

現在（starter 已長高 1 倍，準備放冰箱）
建議立即做（如果還沒放）
1. 先讓它在室溫再靜置 30–60 分鐘（讓剛長高的狀態穩定、把表面活動稍固定）— 若你已經放了，可跳過。 
2. 蓋好（玻璃罐蓋鬆一點即可），放入冰箱 4°C 冷藏。 
3. 在罐外用記號貼標記「放冰時間」，並保留至少 20–30 g 做為備用（不要全部用掉）。 
原因：剛長高立刻冷藏會讓酵母酒化/表現不穩；先穩定 30–60 分可減少過量酒精生成。

冷藏 36 小時後（你打算做 SSS 的時候）——兩條可選路線
路線 A（穩妥推薦）：取出 → 快速 refresh → 做 SSS
步驟：
1. 從冰箱取出 starter，室溫回溫 30–60 分鐘。 
2. 做一次快速 refresh（建議）：1 : 2 : 2（種 : 粉 : 水）或 1 : 3 : 3（更溫和）。
◦ 例：取 20 g seed + 40 g 粉 + 40 g 水（1:2:2）。 
3. 放在 24–26°C，等 6–8 小時（視溫度）到活力回升（有明顯小泡或 1.5–2 倍）。 
4. 用這個剛到峰或剛過峰的液種去接你的 SSS（按你 SSS 的接種比例 20% 或 30%）。 
5. SSS 在 25°C 約 3.5–5 小時 到高峰（接種與溫度會影響時間），以 poke test / 小孔洞 / 味道 判斷是否可用。 
優點：最穩，酸度被稀釋、酵母恢復強度，SSS 發揮最好。

路線 B（節省一步，直接拿冷藏的 starter 去做 SSS）
步驟：
1. 直接從冰箱取出，室溫回溫 30–60 分鐘（非常重要）。 
2. 直接用冷種接 SSS，但請調整：
◦ 把接種量降為 20%（或若你想快可用 30%）。 
◦ 將 SSS 發酵溫度設定在 25–26°C（不要太熱），並預期發酵時間延長：約 4–6 小時 或更久。 
3. 用 poke test / 聞味 / 組織判定 SSS 是否可用（見下方判斷標準）。 
風險與影響：冷藏種活性較弱且酸度可能較高 → SSS 起步較慢，且風味可能偏酸；但如果你時間寬裕，仍能得到可用 SSS。

如何判斷 SSS 活力（不用盯倍數，靠這三個）
在 SSS 建議同時符合下列 2–3 個就可用：
1. poke test：按下去 慢慢回彈、留淺凹痕（不是立刻回彈、也不是完全塌陷）。 
2. 組織：切一小塊看內部有細小均勻孔洞、彈性好。 
3. 味道：微甜或微果香、乳酸感溫和；若是刺鼻醋或強烈酒精 → 風險高（建議 refresh）。 
小提示：玻璃罐的 starter 可視覺觀察「回升」；但 SSS 最可靠仍是 poke/切面/嗅覺。

如果你要直接做 SSS，SSS 的實作小重點（按你常用配方）
• Hydration：52%（你用過） 
• 糖：20%（照你的） 
• 接種：20%（保守）或 30%（更快、酸味更低，但需種強） 
• 溫度：25–26°C 最好（冷藏種用此溫度較穩） 
• 估時間：20% 接種 → 約 4–6 小時到峰；30% → 約 3–4 小時到峰（視起始活性） 

可能的影響總結（你要知道會發生什麼）
• Starter 冷藏 36 小時通常會：
◦ 有部分塌陷或表面出 hooch（正常） 
◦ 酸度可能略升（但不一定刺鼻） 
◦ 活性受抑（需喚醒或 refresh） 
• 結果在 SSS 上會看到：
◦ 若未 refresh → SSS 可能較慢且酸度偏高（影響麵團風味與推力） 
◦ 若 refresh → SSS 跟正常流程無異，表現好且風味佳 

實際建議（一步到底，照做版）
1. 若想最穩妥：36 小時後取出 → 30–60 分回溫 → 做 1:2:2 或 1:3:3 refresh → 等 6–8 小時到活 → 接 SSS（20–30%）→ SSS 在 25–26°C 等 3.5–5 小時到峰。 
2. 若時間有限、要省步驟：36 小時後取出 → 回溫 30–60 分 → 直接接 SSS（用 25% 左右接種）→ 把 SSS 溫度控制在 25–26°C，預期 4–6 小時到峰，並以 poke + 嗅覺判斷是否可用。 

最後給你一張「快速決策卡」
• Glass jar 觀察到：若冷藏後塌陷但無霉 → 正常。 
• 取出後若 回溫 30 分內有小泡 → 可直接接 SSS（用 25%）或做 1:2:2 更穩。 
• 若 回溫 1–2 小時無任何活動或味道非常刺鼻 → 丟或用 1:3:3 強化救援（但若刺鼻霉味則丟）。

0053_麥子／麵粉裡的水量會決定物理狀態、分子活動力與生化反應的強弱

0053_麥子／麵粉裡的水量會決定物理狀態、分子活動力與生化反應的強弱

解釋這張圖的意思

圖解重點（一步看懂那張「5 個關鍵含水點」圖）
這張圖想說的核心是：麥子／麵粉裡的水量會決定物理狀態、分子活動力與生化反應的強弱。不同含水區間，麵團/麵糊的行為（可加工性、酵素活性、發酵速率、孔洞形成、風味發展）會有質的改變——圖把這些臨界點整理成 5 個「cardinal hydration points」(A–E)。下面把圖裡的元素拆成容易理解的實務說明。

圖中幾個重要軸與詞彙（先了解符號）
• 水平軸：代表「含水量（% of fresh weight / hydration level）」，右邊越高越濕。 
• 狀態欄（porous glass → glass → leather → rubber → syrup → solution）：描述麵粉/麵團在該含水下的宏觀物態（從很硬像玻璃到像溶液）。 
• binding sites / RH / ψ (水勢)：科學上說明水如何被結合或以自由水出現，會影響微生物與化學反應。 
• 上方箭頭：顯示在更高含水下會打開哪些生化過程（酵素活性、呼吸、蛋白合成、梅納反應等）。 

五個關鍵含水區間（A → E）與實務意義
A（很低含水，約 0–~33%）
• 物態像：porous glass / glass（很乾硬） 
• 特性：分子幾乎不動，酵素/微生物活性極低。 
• 實務：這種含水下絕對做不出麵糰（粉塊），適合保存或乾性混合。 
• 例子：極乾的全粒粉片或儲粉狀態。 
B（低–中含水，約 45–48% 範圍起點）
• 物態像：leather（皮革感）到開始變得親水 
• 特性：水開始把蛋白質與澱粉潤濕、分子活動增加，酵素開始工作。 
• 實務：傳統「硬式 starter / stiff starter」常在這個區域（你做的 SSS ~52% 就緊鄰此區域）。麵糰較結實、易塑形，但活動性較低。 
C（中等含水，約 49–69%）
• 物態像：rubber（有彈性） 
• 特性：分子活動良好，麵筋網形成、延展性與氣體保持力最好；酵母和酵素活性穩定。 
• 實務：大多數普通麵包（50–70% hydration）落在此區，既好操作又能發出好孔洞（依配方與整形決定）。這是「做麵包最舒服的區間」。 
D（高含水，約 85–95%）
• 物態像：syrup（糖漿狀） 
• 特性：接近飽和，分子高度流動，發酵、酵素作用非常活躍；自由水多。 
• 實務：這是做 非常濕的發酵糊 / biga、levain 高水量、sourdough sponge 的區域。發酵更快，風味發展也更強，但操作更難（黏、流動）。 
E（超高含水，>100%）
• 物態像：solution（溶液） 
• 特性：麵粉幾乎完全溶解成糊或湯，分子自由活動最大。 
• 實務：你看到的 120% hydration（wildhearth 的做法）就是此類，是用來「快速自發發酵、最大化微生物活動」的實驗/坊級方法。 

實務結論 — 對你做 Starter / SSS / 麵包的具體提示
• SSS（50–55%）：剛好在 B→C 間，利於抑制過多酸（因為酵母在這水量下有競爭優勢）且仍有足夠結構易操作 → 這就是為什麼 SSS 比 liquid starter 酸味低、耐峰時間長的原因之一。 
• 一般麵包（60–75%）：落在 C 區，最容易得到開放孔洞與好延展性（如果你想要大孔、潤澤心層，調到這區）。 
• 想要快速出現強烈野生發酵（像 wildhearth）：把 hydration 推到 D 或 E（85%+ / 100%+），酵母與乳酸菌動得快速，口味劇烈但也風險高（不穩定）。 
• 控制發酵與風味：靠的不是單一數字，而是「水量 + 溫度 + 接種量 + 麵粉特性（灰分/提取率）」。
◦ 同一含水下，高灰粉（T130、85% extraction）會比低灰粉更快被微生物利用。 

一張超簡化速查表（給你帶到廚房）
• < 40%：很硬、難發酵 → stiff starter、成型方便 
• 45–60%：可控、適合 SSS、甜麵包、整形方便 
• 60–75%：一般麵包好用 → 易形成大孔（需技巧） 
• 75–95%：非常濕 → 易發酵、風味強但難操作 
• >100%：糊 / 湯狀 → 速發酵/實驗用，不適合一般整形

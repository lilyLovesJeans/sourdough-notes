我在前48小時做的starter,總重量應該是200g左右，只要留20g? 為什麼？

這是新手最容易疑惑的地方，我用 超白話、科學＋實務 方式一次講清楚 👇

✅ 為什麼前 48 小時做出的 starter（大約 200g），後面只要留「20g」？
原因只有一個：
👉 Starter 的目的不是保存「量」，而是保存「菌的品質」。
Starter 是一個微生物的世界。 你需要的不是那 200g 的 重量，而是那 20g 裡面所包含的 健康、活力強的菌群。

🔬 為什麼 20g 就足夠？（科學原因）
✔ Starter 每次餵養後會重新「繁殖」
即使只留 20g，只要餵：
• 20g 麵粉 
• 20g 水 
它就會長成 60g。 菌的繁殖速度非常快，遠比你想像的更驚人。
✔ 越少的「舊 starter」→ 酸味更低
Starter 放越久，乳酸菌越多、酸度越強。 留太多「舊 starter」會讓酸隨著天數積累。
→ 留少（20g）、餵多（20g+20g） = 酸被稀釋 = 酵母重新大量繁殖 = Starter 更甜、更強壯、更穩定
✔ 世界所有專業麵包師都是留 10–20g
這不是隨便定的數字，是經驗＋微生物科學驗證過的習慣。

🧪 如果你留很多（例如 100g）會怎樣？
1. 酸味累積更快（會變很酸） 
2. 餵養成本變高（每天要餵大量麵粉/水） 
3. starter 容易失衡（酵母弱、酸菌多） 
4. 容易爆罐（體積太大、但菌群還沒健康） 
所以留大量 starter → 完全沒有優點，只有缺點。

🍞 那我前 48 小時做出的 200g 怎麼辦？
✔ 正確做法：
1. 第一次 refresh 　→ 倒掉 180g，只留 20g 
2. 餵 20g 粉 + 20g 水 
3. 得到 60g 
4. 24 小時後再 refresh 　→ 又留 20g 
5. 連續做 3–5 天 　→ 你的 starter 才真正成熟 

📌 最重要的觀念：倒掉不是浪費，是必要。
Starter 的第一週，大部分重量都是：
• 過度滋生的雜菌 
• 野生酵母的早期階段（力道很弱） 
• 酸味很重的細菌 
倒掉這些是讓 starter「淨化」，讓健康的菌佔主導。
倒掉是 starter 成功的關鍵，不是浪費。

🧡 如果你想保留更多量怎麼辦？
你必須先讓 starter 成熟（完成 5–7 天 refresh）， 成熟後才可以放大：
取 20g → 餵 60g 粉 + 60g 水 → 得 140g 再取 20g → 餵 100g + 100g → 得 220g ……這樣放大才安全又不酸。

💡 一句話總結
starter 成功的關鍵不是「重量」，而是「健康菌的比例」。
所以留 20g 是最能保持菌種強壯、甜味高、酸度低的方式。

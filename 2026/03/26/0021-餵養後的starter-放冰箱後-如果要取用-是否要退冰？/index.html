0021_餵養後的starter 放冰箱後 如果要取用 是否要退冰？

所以如果 餵養後的starter 放冰箱後 如果要取用 是否要退冰？

完全正確。 從冰箱取出的 starter，一定要先退冰（回溫）並餵養活化後，才能拿去做麵包。
下面我把「冰箱 starter 的使用流程」寫成最清楚的新手版。

🧊 冰箱 Starter 使用流程（新手也不會失敗版）
✔ STEP 1：從冰箱取出
冷藏的 starter 是 休眠 的，酵母活動非常低。 此時不能直接用來做麵包（發不起來、萎弱、變酸）。

✔ STEP 2：放室溫 30–60 分鐘（退冰）
目的：
• 讓溫度回到 24–27°C，讓菌開始重新活動 
• 這階段 還不會明顯起泡，很正常 

✔ STEP 3：正常餵養（refresh）一次
這步非常重要！
餵養比例：1:1:1 或 1:2:2
例如：
• 20g starter → 加 20g 水 + 20g 麵粉（產生 60g） 
• 或做更強：20g starter → 加 40g 水 + 40g 麵粉（產生 100g） 

✔ STEP 4：等它「活化到頂」
活化標準：
✓ 4–8 小時膨脹 2–3 倍 ✓ 表面均勻小氣泡 ✓ 中間爆發力強 ✓ 用湯匙挖起來有絲狀拉力 ✓ 香味微酸、奶香而非刺鼻酸
這時才能取用做麵包。

✔ STEP 5：取需要的量
例如你需要 80g，就從活化好的 starter 裡挖 80g 去用。

✔ STEP 6：剩下的再餵一次 → 再放回冰箱
流程：
1. 剩下的 starter 留 20g（或你習慣的量） 
2. 餵養（20:20:20） 
3. 等發一點點（不用到頂） 
4. 放回冰箱休眠 

📌 補充：不能直接從冰箱拿就用的原因
如果你跳過活化：
❌ 酵母力量弱 → 麵團發不起來 ❌ 會產生過酸 → 麵包帶強烈酸味 ❌ 發酵時間會不穩 → 可能整個批次失敗

📘 一句話總結
冰箱 starter → 退冰 30–60 分 → refresh 一次 → 活化到頂 → 才能取用。

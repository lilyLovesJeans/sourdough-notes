起種一定要玻璃瓶嗎？塑膠罐可以嗎？ 容積大小會影響發酵嗎？

不用一定玻璃瓶，塑膠罐也可以，只要符合幾個條件。下面我幫你分成「材質」「大小」「形狀」三部分講，非常簡單清楚。

✅ 一、玻璃瓶 vs 塑膠罐 — 哪個比較好？
✔ 玻璃瓶（最佳）
優點：
• 不吸味、不染色 
• 易觀察高度（透明） 
• 耐酸耐熱（液種 pH 約 3.5–4） 
• 不會隨時間變形 
缺點：
• 摔到會破 
• 稍微重 

✔ 塑膠罐（可用，但需注意）
可用，不影響起種，只要：
✔ 選擇 PP 或 PET 塑膠（食品級）
• PP（聚丙烯）：最安全，可以耐一點溫度（70–90°C） 
• PET（寶特瓶那種）：也能用，只是不耐高溫 
不要用：
• PVC 
• PS（保麗龍類） 
• 會吸味或太軟的塑膠 
✔ 注意溫度
放烤箱（不開熱源）＋熱水杯時，內部約 26–30°C → 塑膠完全沒問題 → 不會熱到釋放有害物質
✔ 缺點
• 表面容易刮傷（藏菌） 
• 長時間使用（半年以上）可能吸味 
• 不透明不好觀察高度（可以貼紙或畫線解決） 

✅ 二、容積大小會影響發酵嗎？
會，但影響方式很簡單：
① 起種初期 → 小瓶比較好（250–400 ml）
原因：
• 液種前 48 小時很弱 
• 小體積比較穩定、升溫快 
• 不易形成「死角」或局部過酸 
✔ 最佳容量：300 ml 透明瓶（玻璃或塑膠皆可）

② Refresh 後的成熟液種 → 500 ml 更保險
因為成熟液種會漲到 2～3 倍：
• 24 g 種 + 24 g 水 + 24 g 麵粉 = 72 g → 發酵後可能膨脹到 150–200 ml → 小瓶（300 ml）還能塞得下 → 但瓶子太小可能頂蓋（不理想） 
✔ 建議：
• 平常用 300–500 ml 的瓶子 
• 只留半瓶空間讓它長高 

✅ 三、瓶子形狀會影響效果嗎？
有：
✔ 直立型（細長玻璃罐）最佳
理由：
• 高度變化明顯（好判斷是否膨脹 2–3 倍） 
• 表面積小 → 減少表皮乾裂 
✔ 廣口短胖罐（寬罐）也可用
優點：好攪拌 缺點：高度變化不明顯、表面偏大

🔥 最簡單選擇（你可以直接拿家裡的用）：
優先順序：
1. 透明玻璃瓶 300–500 ml 
2. 透明 PP 塑膠罐 300–500 ml 
3. 不透明 PP 塑膠罐 300–500 ml（外面貼紙畫線）

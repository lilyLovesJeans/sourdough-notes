0015_Day2 到底要不要「倒掉」

0015_Day2 到底要不要「倒掉」

但是之前說 day2不用倒掉，直接餵50粉+50水

你問得非常好！
因為——Day2 到底要不要「倒掉」？要 20/20？還是 50/50？
這的確在不同烘焙老師的版法中會看到兩種做法，但它們不是矛盾，而是：

⭐ 兩種不同的建種路線（都可以成功）。

我來一次講清楚：「兩種方法的差別、什麼情況用哪一種」。

🟦 為什麼之前我給你 50g 粉 + 50g 水？

因為你之前問的是：

🤔「新手第一次起 starter，要怎麼做？能不能更保險？」

對新手來說：

⭐ “不倒掉、直接餵 50/50” = 更穩定、更容易成功的新手路線

理由：

  • 你 Day1 的菌量還不大
  • 你 Day1 也不會蓋太死
  • 你 Day1 的 starter 還沒進入酸敗期
  • 不倒掉 → 菌相比較穩定更容易建立
  • 加 50/50 → 給很多食物，讓微生物調整更快

也就是說：

👉 新手使用 50/50 餵法 → 成功率高、不容易失敗

這是一種「溫柔、不急速」的養法。

🟧 那 20g＋20g、還要倒掉的版本是什麼？

這是：

⭐ “專業烘焙師用的較快、菌種變化更強烈的路線”

適合：

  • 室溫理想（24–26°C）
  • 你對 starter 有基本認識
  • 已能判斷發酵狀態
  • 想讓酵母更快強化
  • 想讓酸敗部分更快被刷新掉

倒掉 → 更快降低酸度
餵 20/20 → 菌密度高，培養更強的酵母群落

但對新手來說：

  • 倒掉太快可能造成「酵母被稀釋到太少」
  • 室內溫度太高會延長酸敗期
  • 有時反而 Day4–Day5 會變很慢

也就是：

👉 倒掉 100g，留 20g 的方法比較快但比較“刺激”，需要經驗。

🟩 所以：你實際應該用哪一種？

你現在在台灣氣候（24–30°C甚至更高）、第一次做 starter，我會給你最不會失敗的：

⭐ 新手最穩定的「不倒掉 Day2 餵 50/50」養法

Day2：

  • 不倒掉
  • 加 麵粉 50g + 水 50g

好處：

  • 酸度不會太快下降
  • 酵母不會被過度稀釋
  • 微生物有充足食物
  • 成功率高
  • 不需要判斷複雜狀態

換句話說：

⭐ 新手先用“溫和養法（50/50）”，等 starter 穩定，再用倒掉法。

🟥 可以整理一下兩種方法的差異嗎？

方法 Day2 做法 優點 缺點 適合誰
溫和法（新手法） 不倒掉 → 餵 50粉+50水 成功率高，穩定，不需要經驗 相對比較慢（但安全） 新手、第一次起種、熱氣候
專業快速法 倒掉 100 留 20 → 餵 20粉+20水 酵母更快變強、建立更乾淨的菌相 需要判斷能力，新手會失敗 熟手、室溫 24–26°C、追求效率

🟩✨ 結論（最重要）

✔ 你用新手方法：Day2 不倒，餵 50/50 → 完全正確！

兩個版本都對，但你的情況應該用 不倒掉的版本。

📌 「不倒掉版本 Day0〜Day7」完整每日操作
📌 + 每天會看到什麼味道、泡泡、質地變化
📌 + 失敗現象（怎麼救）
